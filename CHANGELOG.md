# Changelog

## 0.1.0 - 2026-09-06

- Añadido el CLI `python -m blackzero` para una o varias URL.
- Añadidos destinos y nombres configurables, colisiones seguras, reintentos, timeout, modo silencioso, reanudación y checksum SHA-256.
- Añadida finalización atómica mediante archivos `.part` y códigos de salida estables (`0`, `1`, `2`).
- Se mantiene la compatibilidad con `python DownloadFiles.py`, incluido el flujo interactivo sin argumentos.
